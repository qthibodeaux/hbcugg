# 0-data — Legacy Analytics Exports

Last updated: 2026-04-19

This folder contains **aggregated analytics and unified exports** generated by the `5-enrichment/` pipeline. These are higher-order outputs — pre-computed summaries, career arcs, continuity scores — that don't fit neatly into the per-entity folders (`3-players/`, `4-coaches/`, `5-officials/`).

> **Note:** Most raw entity data (rosters, coaches, officials) has been superseded by files in `3-players/`, `4-coaches/`, and `5-officials/`. See the relevant sections below for what to use instead.

---

## Files

### `team_continuity_2021_2025.json`
**Generator:** `5-enrichment/analytics/team_continuity.py`  
**Active reader:** `27-Why/context_resolver.py` — loaded for every Why Engine call

Team-level staff and roster stability scores across 2021–2025.

| Key | Description |
|---|---|
| `league_summary` | League-wide continuity stats |
| `teams` | Per-team object keyed by `team_id` |
| `teams[id].continuity_score` | 0–1 composite score |
| `teams[id].continuity_grade` | A–F letter grade |
| `teams[id].staff_stability_score` | Coaching retention component |
| `teams[id].roster_experience_score` | Returning player experience component |
| `teams[id].head_coach_history` | List of HC tenures with years |
| `teams[id].coaching_retention` | Year-over-year retention rates |
| `teams[id].roster_composition_2025` | Class year breakdown for most recent season |

---

### `coaching_trees_2021_2025.json`
**Generator:** `5-enrichment/analytics/coaching_trees.py`  
**Active reader:** None (reference/display use)

Career arc and lineage data for all coaches in the system.

| Key | Description |
|---|---|
| `career_progressions` | 221 coach career arc records |
| `career_progressions[].arc_type` | `coordinator_to_head` · `position_to_coordinator` · `position_to_head` · `stable` |
| `staff_relationships` | 854 coach→coach staff pairing records |
| `program_transfers` | 11 coaches who moved between tracked programs |
| `summary` | Aggregate counts by arc type, most stable programs |

### `coaches_multi_year_analytics.json`
**Generator:** `5-enrichment/create_multi_year_exports.py`

| Key | Description |
|---|---|

### `coaches_2021_2025_frontend_ready.json`
**Generator:** `5-enrichment/create_multi_year_exports.py`  
**Active reader:** None — superseded by `4-coaches/coaches_all_years.json`

**Prefer `4-coaches/coaches_all_years.json`** for season-level coach data (2,426 records, full 2010–2025 coverage).

### `player_analytics_2025.json`
**Generator:** `5-enrichment/analytics/enhanced_player_analytics.py`  
**Active reader:** None

Pre-computed 2025 roster analytics. Does **not** use the new enrichment fields (distance, position_group, etc.) from the current pipeline.

| Key | Description |
|---|---|
| `transfer_analytics` | Transfer rate, tier breakdown, position impact |
| `class_analytics` | Class year distribution and experience metrics |
| `position_analytics` | Position group distribution and depth |

**Note:** The roster hub (`2-schools/roster_hub_*.json`) now provides equivalent analytics with the correct updated schema.

### `player_stats_2025_enriched.json`
**Generator:** `5-enrichment/analytics/player_performance_bridge.py`  
**Active reader:** None — superseded by `3-players/player_seasons_2025.json`

Person-matched enriched player stats for 2025 only. 1,054 players, 91% match rate.  
Schema: `{ season, players: { [person_id]: { ...stats, position_group, class_year, ... } } }`

**Prefer `3-players/player_seasons_2025.json`** — full schema, all enrichment fields.

---

### `ALL_2021_2025_entities_frontend_ready.json`
**Generator:** `5-enrichment/generate_unified_export.py`  
**Active reader:** None

Large (~3.5MB) unified dump combining teams, coaches, and a thin player layer in one envelope. Player records here have minimal fields (`name`, `position`, `image_url`, `seasons` only).

Not recommended for active consumption — use the per-entity files in `3-players/`, `4-coaches/`, `5-officials/` instead.

## How to regenerate

Run these in order:

```bash
python3 5-enrichment/analytics/team_continuity.py
python3 5-enrichment/analytics/coaching_trees.py
python3 5-enrichment/analytics/enhanced_player_analytics.py
python3 5-enrichment/analytics/player_performance_bridge.py
python3 5-enrichment/create_multi_year_exports.py
python3 tools/referees/build_frontend_export.py
```

Then copy outputs from `5-enrichment/frontend_exports/` to this folder. The `11-entity/build_frontend_exports.py` script handles the per-entity files in the other folders automatically.
